# WorkBuddy 项目记忆

**工作背景**
商务车排班系统 WorkBuddy 的开发者，技术栈为 Windows + Node.js。用户作为汽车运输从业者，长期担任商务车服务乙方，同时运营贵阳白云巴士小红书蓝V账号。当前正推进排班系统的功能迭代，涵盖航班/高铁准点延误取消标签（含延误时间输入）、排班页面多状态筛选、车辆安排选项及弹窗信息优化，以及企业微信配置功能的开发。

**个人背景**
中文交流为主，沟通风格偏好截图驱动的迭代式 UI 优化方式，重视具体视觉反馈而非纯文字描述。在业务实践中面临服务标准认定争议及压缩用车导致司机情绪等合同问题，正准备向白云巴士客运公司提交自荐 PPT 方案。

**排班规则**
- 飞机出发提前量60分钟，高铁出发提前量40分钟
- 飞机趟次间隔150分钟，高铁趟次间隔100分钟
- 每辆车趟数均衡分配，交通类型（机场/高铁）均衡分配

**UI/UX 说明**
- 导航菜单：首页、客户管理、车辆管理、临时录入客户、排班方案、调度看板
- 已删除"排班详情"页面，保留"调度看板"作为唯一排班查看入口
- 客户列表有状态筛选（正常/延误/取消）和操作按钮

**近期完成**
- 航班/高铁准点/延误/取消标签（含延误时间输入）及对应筛选功能
- 延误登记弹窗、取消登记弹窗、恢复正常功能
- 变更日志记录功能
- 合并排班详情和调度看板
- 每组客人独立用车的排班规则更新
- 排班规则优化：飞机150分钟、高铁100分钟，动态间隔，车辆提前到达
- 客户管理新增"清除客户"按钮
- 车辆管理新增"清除车辆"按钮
- **客户管理页面整合**：新增"新增客户"按钮（右上角），点击弹出临时录入客户表单，通过 AddCustomer 录入的客户在列表中显示绿色"新增"标签
- **删除临时录入客户独立页面**：功能已整合到客户管理页面，导航菜单中也已移除该入口
- **排班均衡分配算法**：新增趟次均衡和交通类型均衡机制，每辆车的总趟数和机场/高铁任务数尽量平衡分配
- **预计用车实时预览**：导入客户后即时显示预计用车数量，数据看板的预计用车卡片改为实时计算而非依赖排班结果
- **预计用车算法精简**：简化为按人数统计（每车最多4人，超过4人需2辆），不再使用复杂的排班逻辑估算（时间间隔/趟次限制是排班时才考虑的约束）
