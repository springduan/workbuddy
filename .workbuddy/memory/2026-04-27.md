# 2026-04-27 工作记录

## 自动通知功能方案讨论

**需求**：排班生成后，自动通知业务员和司机：
- 业务员收到：客户信息 + 司机车牌/电话
- 司机收到：业务员姓名/电话 + 接机信息

**通讯环境**：
- 用户本人：企业微信 + 个人微信
- 业务员/司机：仅个人微信（约100名业务员，司机临时调配不固定）
- 不使用企业微信，排除「上下游」方案

**确定技术方案**：微信小程序订阅消息
- 业务员/司机打开小程序后授权，即可接收推送
- 无需下载任何App
- 费用约¥30-50/月（云服务器）

**通知触发机制**：
- 排班生成后不自动发送，由用户手动点击「发送通知」
- 支持全部发送 / 单独选择 / 单独发送
- 支持延误/取消时的变更通知
- 状态=取消的行程自动排除，不发送

**代码备份**：
- 打了 Git tag `v1.0-stable` 保存稳定版
- 新建并切换到分支 `feature/wechat-notify` 用于小程序开发
- 用户可随时切回 main 分支回退
