### "重新排班"功能完善（22:53）

**问题**：原来 `generateSchedule` 每次调用会**追加**新任务到旧任务上，导致重复排班
**修复**：
- `useAppData.ts`：`generateSchedule` 改为**先清除旧排班再重新生成**
- `generateSchedule` 返回消息增加详细信息：延误客户数、取消排除客户数
- `CustomerList.tsx`：点击"重新排班"按钮后显示 toast 成功/失败提示
- `onReschedule` 类型从 `() => void` 改为 `() => { success: boolean; message: string }`
