## 小程序问题修复

### 问题描述
用户用新手机号注册登录后，之前发送的任务仍然出现在新账号里，且无法识别新注册的手机号。

### 根本原因
微信小程序的 `openid` 与微信号绑定，不是与注册手机号绑定。同一个微信账号无论换多少次手机号，`openid` 始终不变，导致旧任务记录（按 `openid` 存储）仍会显示。

### 修复内容
1. **后端 `server/index.js`**：新增 `DELETE /api/tasks` 接口，允许用户清除自己的任务记录
2. **小程序 `pages/index/index.js`**：新增 `clearAllTasks()` 方法
3. **小程序 `pages/index/index.wxml`**：任务列表标题旁新增「清除记录」按钮
4. **小程序 `pages/index/index.wxss`**：添加清除按钮样式
5. **修复 `sitemap.json`**：修正字段名 `value` → `page`

## 多用户权限系统开发

已完成以下开发：

### 数据库
- 新建 `admin_users` 表（账号/密码hash/姓名/角色/创建时间）
- 默认管理员：admin / admin123

### 后端 API (server/index.js)
- POST /api/admin/login - 登录
- GET /api/admin/me - 获取当前用户
- POST /api/admin/logout - 登出
- GET /api/admin/users - 获取用户列表
- POST /api/admin/users - 创建用户
- PUT /api/admin/users/:id - 更新用户
- DELETE /api/admin/users/:id - 删除用户
- POST /api/admin/users/batch - 批量导入

### 前端
- 更新 Login.tsx 使用异步登录
- 新建 UserManagement.tsx 用户管理页面
- 更新 Layout.tsx 根据角色显示菜单
- 更新 App.tsx 添加用户管理路由

### 权限控制
- 员工账户：隐藏「配置」和「用户管理」菜单
- 管理员账户：显示全部菜单

### 使用说明
1. 启动后端：cd server && node index.js
2. 默认账号：admin / admin123
3. 管理员可添加/编辑/删除员工账户
4. 支持批量导入 Excel（模板含姓名/账号/初始密码/角色列）
