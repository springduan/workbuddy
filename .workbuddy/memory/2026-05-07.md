# 2026-05-07

## 推送功能排查与修复

**问题**：同一手机号无法发送第二次推送（提示"该手机号未注册小程序"）

**根因**：
1. `NotifyConfirmModal.tsx` 推送时 `salespersonPhone` 只取 `customers[0].salesmanPhone`，如果多个客户来自不同业务员，第二次任务的第一个客户手机号不同就会失败
2. db.js 中 `UNIQUE(task_id, openid)` 约束位置错误（放在列定义中间）导致服务启动时 SQL 报错

**修复内容**：
- `db.js`：将 `UNIQUE(task_id, openid)` 约束移到所有列定义之后（SQLite 语法要求）
- `server/index.js`：
  - 区分"未注册"和"已取消订阅"两种错误提示
  - 推送接口增加调试日志（记录接收到的 driverPhone 和 salespersonPhone）
  - 新增 `/api/users/check` 接口：批量检查手机号注册状态
- `NotifyConfirmModal.tsx`：
  - 推送时遍历所有不重复的业务员手机号（而非只取第一个客户的）
  - 推送结果合并去重（防止同一手机号展示多次）

**服务状态**：
- 后端：http://localhost:3000（进程 node index.js，日志 /tmp/server.log）
- 前端：http://localhost:5173 / http://192.168.2.38:5173
